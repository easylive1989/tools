# 鉅亨網台股新聞 — Raycast 原生 Extension

透過 Raycast 原生 React + TypeScript UI 呈現的鉅亨網即時台股新聞閱讀器。

## 功能特點

- **超大字體標題**：右側 Detail 面板以 Markdown `# H1` 超大字體呈現，字級清晰醒目。
- **雙欄式原生介面**：
  - **左側清單**：即時新聞列表，附帶發布時間與圖示。
  - **右側詳情預覽**：點選任一則新聞即時預覽封面大圖、新聞內文摘要、分類、相關個股標籤（如台積電 2330）與原始連結。
- **直覺快捷操作**：
  - `Enter`：直接在預設瀏覽器打開新聞全文。
  - `⌘ + C`：複製該篇新聞網址。
  - `⌘ + R`：手動重新整理新聞資料。
- **即時搜尋過濾**：在 Raycast 頂部搜尋列直接鍵入個股代號或關鍵字即可即時篩選。

## 開發與執行方式

在專案目錄下：

```bash
cd /Users/paulps/Documents/Github/tools/cnyes_extension
npm run dev
```

執行後 Raycast 會自動載入此擴充功能。直接在 Raycast 輸入 `鉅亨網台股新聞` 即可使用！
